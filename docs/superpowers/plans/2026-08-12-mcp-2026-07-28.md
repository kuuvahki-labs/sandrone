# MCP 2026-07-28 Strict-Version Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Sandrone's MCP endpoint to the `2026-07-28` protocol and current Go SDK interfaces, accepting no older MCP lifecycle or protocol revision.

**Architecture:** Keep the official Go SDK transport and add one Sandrone receiving middleware as the strict protocol-policy boundary. Run Streamable HTTP statelessly, advertise explicit immutable capabilities, attach private cache metadata at the result boundary, and keep existing Sandrone tools/resources/prompts and service orchestration unchanged.

**Tech Stack:** Go 1.25, `github.com/modelcontextprotocol/go-sdk` v1.7.0, Streamable HTTP, `net/http`, Testify, existing Sandrone service/domain layers.

## Global Constraints

- `internal/entry/mcpapi.ProtocolVersion` is the only accepted and advertised revision: `2026-07-28`.
- Do not retain `initialize`, initialized notifications, session IDs, old-revision negotiation, compatibility environment flags, or an SDK fork.
- Preserve tool names, resource URIs, prompt names, schemas, output limits, authentication, management-mode selection, service calls, and structured domain error semantics.
- Use the low-level `Server.AddTool` wrapper because Sandrone owns field-aware validation and the success/error output-schema union.
- Advertise tools, resources, and prompts only; no logging, roots, sampling, subscriptions, list-change flags, or extensions.
- Cache discover and list results privately for 300000 ms; cache resource reads privately for 0 ms.
- Keep the user's unrelated Web changes untouched.
- Run focused tests after each task and `make check` before completion.

- [ ] **Step 3: Implement one canonical revision and receiving middleware**

Create `protocol.go` around these public SDK interfaces:

```go
const (
	ProtocolVersion   = "2026-07-28"
	privateCacheTTLMS = 300_000
)

type protocolVersionRequest interface {
	ProtocolVersion() string
}

func protocolPolicyMiddleware(next mcp.MethodHandler) mcp.MethodHandler {
	return func(ctx context.Context, method string, req mcp.Request) (any, error) {
		requested := requestProtocolVersion(method, req)
		if method == "initialize" || requested != ProtocolVersion {
			return nil, unsupportedProtocolVersion(requested)
		}
		result, err := next(ctx, method, req)
		if err != nil {
			return nil, err
		}
		applyProtocolPolicy(result)
		return result, nil
	}
}
```

`requestProtocolVersion` reads `ProtocolVersion()` from current requests and uses `InitializeParams.ProtocolVersion` only as rejected-request context. `unsupportedProtocolVersion` returns `*jsonrpc.Error` with code `-32022` and marshalled `mcp.UnsupportedProtocolVersionData{Supported: []string{ProtocolVersion}, Requested: requested}`.

`applyProtocolPolicy` must:

- replace `DiscoverResult.SupportedVersions` with the singleton canonical version;
- set `DiscoverResult`, `ListToolsResult`, `ListPromptsResult`, `ListResourcesResult`, and `ListResourceTemplatesResult` to `300000`/`private`;
- set `ReadResourceResult` to `0`/`private`.
