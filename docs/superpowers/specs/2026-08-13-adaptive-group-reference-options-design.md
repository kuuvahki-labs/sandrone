# 自适应地区组引用选项设计

## 目标

生成或重新生成自适应地区组后，让这些地区组立即作为代理组引用出现在：

1. 其他代理组的固定成员选择器；
2. 路由规则的策略选择器。

地区组继续保持代理组语义，不进入订阅预览产生的真实节点列表。

## 数据边界

- `nodeOptions` 只来源于当前订阅预览及目标格式投影，继续表示真实节点。
- 自适应生成结果通过现有 `applyConfigEditorAdaptiveGeneration` 写入
  `editorState.structure.groups`。
- 代理组成员和规则策略继续通过共享引用模型读取 `groups`；不新增第二套地区组
  状态，也不把地区组复制进 `ConfigNodeSummary[]`。

## 交互行为

- 用户点击生成后，编辑器使用新的 `structureRevision` 重建依赖代理组列表的字段，
  使新生成的地区组无需刷新页面即可选择。
- 代理组成员选择器中，地区组以“代理组”类型展示；当前正在编辑的代理组仍不能
  引用自身。
- 规则策略选择器中，地区组以“代理组”类型展示。
- 删除或重新生成地区组后，选择器使用最新的代理组集合，不保留过期候选项。

## 范围外

- 不改变自适应地区匹配、命名、插入顺序或配置序列化。
- 不改变节点数量、节点校验或订阅预览。
- 不新增专用“地区节点”类型。

## 验证

- 集成测试从订阅预览生成至少一个地区组，确认无需刷新即可在另一代理组的成员
  选择器中看到该地区组。
- 同一测试确认规则策略选择器可以选择该地区组。
- 确认地区组候选标记为代理组而非节点，并且真实节点选项保持不变。
- 运行配置编辑器集成测试、引用模型测试和 Web 类型检查。
