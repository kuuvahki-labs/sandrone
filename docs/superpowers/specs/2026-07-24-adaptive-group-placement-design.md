# 自适应地区组插入位置设计

## 目标

将自动生成的地区组视为供上层策略引用的辅助组，避免它们打断节点选择和应用
分流组的阅读顺序。

## 插入规则

生成或重新生成自适应地区组时：

1. 将所有生成的地区组连续追加到代理组列表末尾。
2. 保持所有非自适应组原有的相对顺序。

地区组在主 Proxy 组成员列表中的位置不变，仍作为主选择组的候选项插入；
本次只调整代理组列表本身的展示顺序。

## 兼容行为

- 重新生成时先移除可安全替换的旧地区组，再按新规则插入。
- 同名自定义组、外部引用保护和节点名称冲突处理保持不变。
- Mihomo、Shadowrocket 和 sing-box 共用相同的插入算法。
- 不新增 `hidden` 字段，不改变客户端配置格式。

## 验证

- 测试中文和英文模板中的地区组都连续位于列表末尾。
- 测试自定义配置不含最终兜底组时仍追加到末尾。
- 运行自适应分组聚焦测试和 Web 全量门禁。
