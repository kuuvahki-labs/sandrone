# 资源显示名称统一设计

## 目标

订阅和文件出现在用户可见的列表或选择器中时，统一优先显示
`display_name`；未设置显示名称时回退到资源 `name`。

## 展示规则

- 主展示文本使用前端资源模型的 `title`，其值为 `display_name || name`。
- 设置了显示名称且它与 `name` 不同时，同时以辅助文本展示 `name`，避免多个资源
  使用相同显示名称时无法区分。
- 搜索同时匹配 `title` 和 `name`。
- 表单值、资源引用、路由参数、API 参数和组件 key 继续使用 canonical `name`。
- 缺失或已删除的资源无法解析显示名称时，直接展示已有的 `name`。

## 改动范围

- 组合订阅的来源多选器。
- 结构化文件配置的订阅节点来源选择器。
- Raw 文件配置的订阅选择器。
- 已经使用 `title` 的订阅/文件主列表、定时更新目标和脚本文件选择器保持现有
  行为，并补足必要的重名辨识能力。

不改变后端资源模型、存储格式或引用语义。

## 验证

- 组件测试覆盖显示名称优先、内部名称辅助显示以及提交值仍为 `name`。
- 运行相关 Web 窄测、类型检查和 lint。
