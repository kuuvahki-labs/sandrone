# 设置页信息架构与响应式布局设计

## 目标

将 `/settings` 从所有配置平铺在同一页面的管理表单，调整为清爽、可渐进进入的
产品设置体验：

- 常用设置留在首页，低频或复杂功能进入独立子页面。
- PC 与移动端保持同一阅读顺序，不依赖宽屏双栏重新编排内容。
- 缩短设置首页，弱化低频危险操作和高级参数对首屏注意力的占用。
- 为后续增加更复杂的高级配置保留稳定入口。

## 当前问题

当前页面按“两列、全宽、全宽、两列”排列多个等权重描边卡片，形成不稳定的
横向节奏。运行默认值默认展开成长表单，数据管理警告占据强视觉权重，且全宽
保存按钮进一步放大各区块。页面标题也使用大型描边容器，但没有承载说明或操作。

## 信息架构

### 设置首页

`/settings` 使用单栏并按使用频率排列：

1. **外观与语言**
   - 主题模式
   - 语言
2. **服务连接**
   - Public Base URL
   - 该分组自己的保存操作
3. **高级设置**
   - 只显示入口标题和进入指示，不显示配置类别或内容摘要。
   - 进入 `/settings/runtime`。
4. **数据与账户**
   - “备份与恢复”进入 `/settings/data`。
   - “管理员 token”保留退出登录操作。
5. **关于 Sandrone**
   - 紧凑展示版本、revision 和 GitHub 链接。

“高级设置”不暴露“远程请求、缓存、测活”等当前类别，避免以后配置增长时设置
首页随之变化。

### 高级设置子页面

`/settings/runtime` 页面标题沿用“运行默认值”，并提供返回设置首页的操作。
现有配置按类别使用折叠分组：

1. 远程请求默认展开。
2. 缓存默认收起。
3. 测活默认收起。

保存按钮属于该子页面，只提交完整运行默认值草稿。字段、默认值和服务端
`/v1/settings/runtime` 契约保持不变。

### 数据管理子页面

`/settings/data` 页面标题沿用“数据管理”，并提供返回设置首页的操作。页面集中
展示：

- 明文备份风险警告
- 下载备份
- 选择备份 ZIP
- 所选文件反馈
- 恢复备份及危险确认

下载、恢复、失败重试和确认行为保持不变。恢复成功后，下一次进入高级设置必须
读取恢复后的新运行默认值，不得展示恢复前的缓存值。

## 视觉布局

设置首页不再使用占满内容宽度的大型描边标题卡，改为普通页面标题和简短说明。
本次只调整设置 feature 的标题表现，不改变其他页面的共享标题样式。

PC 上，设置页及两个子页面采用约 `760px` 的单栏内容宽度。内容列在可用区域内
居中，避免表单字段在宽屏上被拉得过长。设置首页的分组使用紧凑卡片：

- 分组标题、相关控件和操作保持在同一视觉边界内。
- 桌面端设置名称位于左侧，控件或操作位于右侧。
- Public Base URL 保存按钮位于“服务连接”分组内，不使用横跨整卡的按钮。
- “高级设置”和“备份与恢复”表现为明确的可进入行。
- 退出登录保持危险色，但不居中放大。

移动端保持与 PC 相同的分组顺序。设置名称与表单控件由横排改为纵排，输入框占满
卡片可用宽度；按钮仍靠近所属设置，不产生独立的全宽操作带。页面继续兼容现有
底部导航，并不得出现横向滚动。

## 组件与数据边界

路由和页面按现有 Web 分层组织：

- `app/routes/settings.tsx` 只装配设置首页。
- 新增窄 route adapter 分别装配 `/settings/runtime` 与 `/settings/data`。
- `features/settings/pages` 分别拥有设置首页、高级设置页和数据管理页。
- `features/settings/sections` 保留可独立测试的外观、服务连接、运行默认值和
  数据管理区块。
- route config 与集成测试中的独立 route 期望同步增加两个子路由。

数据逻辑按页面需求拆分，避免设置首页为不可见的运行默认值或备份功能发起请求：

- 设置首页只加载版本信息，并使用 provider 中已有的界面偏好和登录状态。
- 高级设置页加载和保存运行默认值。
- 数据管理页提供下载与恢复操作。

拆分可以通过聚焦 hooks 完成；页面和 section 不直接调用 API client。恢复操作
需要绕过或失效运行默认值的旧请求结果，确保后续读取新数据。

## 行为与错误处理

- 主题和语言继续在选择后立即生效。
- Public Base URL 与运行默认值继续显式保存。
- 保存成功和加载失败继续使用现有全局 notice。
- 版本加载失败继续显示“暂不可用”，不阻塞设置首页。
- 备份下载失败继续显示错误 notice。
- 恢复失败保留所选文件供重试；恢复期间锁定相关控件；危险确认保持不变。
- 退出登录继续先显示确认对话框。
- 本次不增加未保存离开提示、设置搜索、新配置项或服务端 API。

## 验证

- 设置首页组件测试验证单栏分组顺序、“高级设置”不含内容摘要，以及主题、语言、
  Public Base URL 和退出登录行为。
- 高级设置页测试验证加载、折叠默认状态、字段编辑、保存和加载失败反馈。
- 数据管理页测试验证下载、ZIP 选择、确认恢复、进行中锁定、失败重试和恢复后
  数据新鲜度。
- 路由集成测试验证三条设置路由、子页面返回操作、各页面只加载自己的资源，以及
  route config 期望同步。
- Playwright 响应式测试验证 PC 与移动端布局、底部导航兼容和无横向溢出。
- 实施完成后运行相关聚焦测试、Web 类型检查、lint、全量测试和生产构建。

## 非目标

- 不重新设计全站导航、其他页面标题或 Material UI 主题。
- 不改变运行默认值、备份或认证的服务端契约。
- 不将设置扩展为带搜索、内侧边栏或设置首页宫格的完整设置中心。
